# Bestie Blue Website 💙

A one-page friendship scrapbook for GitHub Pages, made with only HTML, CSS and JavaScript.

## What's inside?
- `index.html` — words, page sections, gallery and invitation.
- `style.css` — pastel blue scrapbook design.
- `script.js` — photo enlargement, dinner pop-up, confetti and WhatsApp share link.
- `images/` — put your six photos here.

## Make it yours
1. Add six JPG pictures to the `images` folder and rename them `photo1.jpg`, `photo2.jpg`, `photo3.jpg`, `photo4.jpg`, `photo5.jpg`, and `photo6.jpg`. No pictures yet? The frames have nice placeholders.
2. Open `index.html` in VS Code and edit the thank-you note between `<!-- PERSONALISE YOUR MESSAGE HERE -->` and its closing `</div>`.
3. In `index.html`, change the title, gallery captions and the signature `your bestie ♡` if you want. You can also change “this Thursday” to a specific date.
4. The pop-up's reply messages are in `script.js`, in the `showAnswer` function.
5. Test with VS Code's Live Server extension or by double-clicking `index.html`.

## Publish with GitHub Pages
1. Make a new public GitHub repository, e.g. `bestie-website`.
2. Upload `index.html`, `style.css`, `script.js`, and the entire `images/` folder **to the root of the repository** (not inside another `bestie-blue-website` folder).
3. In the repo, go to **Settings > Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**. Select **main** and **/(root)**, then **Save**.
5. GitHub will provide a website address, usually `https://YOUR-USERNAME.github.io/bestie-website/`.

### Important
This is a static GitHub Pages website. Clicking YES or “another day” does *not* notify you automatically. The **send me your answer on WhatsApp** link opens a ready-to-send message, and your friend chooses to send it.

Tip: Keep the repo public so GitHub Pages can publish it on a free account, but remember that any photos you upload to a public repo are accessible to others with the link (and the repository itself is public).
